Copy, paste, get paid

The same library, four ways. Pick the surface you need.

// One line gates a route. Needs only your wallet address — no key.
import { requirePayment } from '@piprail/sdk'

app.get('/report',
  requirePayment({ chain: 'base', token: 'USDC', amount: '0.05', payTo: '0xYourWallet…' }),
  (req, res) => res.json({ secret: 42 })   // runs only once paid
)
// Framework-agnostic core — Next.js, Hono, Fastify, Workers, Bun, Deno.
import { createPaymentGate, toInvalidBody } from '@piprail/sdk'

const gate = createPaymentGate({ chain: 'solana', token: 'USDC', amount: '0.05', payTo: 'YourSolWallet…' })

const r = await gate.verify(req.headers['payment-signature'])
if (r.kind === 'paid') /* serve it */;  else /* return 402 r.challenge */
<!-- A plain HTML page. No build, no npm. -->
<script type="module">
  import { PipRailClient } from 'https://esm.sh/@piprail/sdk'

  // In a browser, sign with the visitor's wallet (MetaMask) — never a raw key.
  const client = new PipRailClient({ chain: 'base', wallet: { walletClient } })
  const res = await client.fetch('https://api.example.com/paid')  // 402 → pays → 200
</script>
// Hand a model two tools + a hard spend cap. It pays for what it needs.
import { PipRailClient, paymentTools } from '@piprail/sdk'

const client = new PipRailClient({
  chain: 'base', wallet: { privateKey: process.env.KEY },
  policy: { maxAmount: '0.10', maxTotal: '2.00' }   // refuses to overspend
})
const tools = paymentTools(client)  // piprail_quote_payment + piprail_pay_request
⚠ In the browser, never put a raw private key in your page — source is public. Use the visitor's injected wallet (a viem walletClient from MetaMask). Raw keys belong only in a server's environment.

24 chains, one parameter

USDC almost everywhere, USDT on most, plus each chain's native coin — change one word: chain: 'base' → 'solana' → 'tron' → …. Eight families, no exceptions.

🚫 No backend

Payments settle straight to your wallet, verified locally against your own RPC. No database, no account, no fee.

🪶 Lean by design

EVM needs only viem. Non-EVM chain libs lazy-load on first use — a pure-EVM page never downloads them.

🔒 Self-custody

The payer signs and broadcasts their own transfer. PipRail never holds funds and never takes a cut.

🤖 Built for agents

Spend policy + an approval hook + LLM tools. Point an agent at a paid URL and it pays itself — within budget.
